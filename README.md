# 🧮 Comparison of X

A clean, responsive, and user-friendly web application designed to solve **direct proportion** problems (cross-multiplication). Whether you're calculating ingredient scales, currency conversions, or resource distribution, this tool helps you find the missing value ($X$) instantly.

## ✨ Features

- **Fraction UI:** Intuitive layout that mimics a real mathematical equation.
- **Smart Formatting:** \* **Thousand Separators:** Automatically adds commas (e.g., `3,000`) as you type for better readability.
  - **Decimal Support:** Handles periods (`.`) for high-precision calculations.
  - **Smart Cursor:** Prevents cursor jumping while typing for a smooth user experience.
- **Dynamic Dark Mode:** Toggle between Light and Dark themes via the top-right icon.
- **Fully Responsive:** Optimized for all screen sizes, from mobile phones to desktop monitors.
- **No Alerts:** Error handling and results are displayed directly within a dedicated result box.
- **Emoji Favicon:** Integrated "🧮" icon for a professional browser tab appearance.

## 🚀 Getting Started

1. Download the `index.html` file.
2. Open the file in any modern web browser.
3. No installation or internet connection is required.

## 📖 How to Use

The calculator follows the standard ratio formula:

$$\frac{A}{B} = \frac{C}{X}$$

To find $X$:
$$X = \frac{B \times C}{A}$$

1. Enter the known ratio in the first fraction (**A** and **B**).
2. Enter the known value of the second ratio in the top-right box (**C**).
3. Click **"Calculate X"**.
